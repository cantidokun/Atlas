============================================================
1. PROJECT DIRECTION
============================================================

Atlas is an AI-assisted sports virtual production and digital-twin platform.
Blender is the first execution environment being brought to full agent operation.
Unreal Engine is a planned complementary production environment.

Dedicated photogrammetry software is an upstream stage that creates the initial
3D reconstruction. Blender receives that reconstruction for analysis, cleanup,
correction, optimization, and preparation. Photogrammetry is not a Blender
responsibility.

Core authority model:

Qwen / AI
    -> understand, reason, propose

Python / Atlas
    -> validate schemas, authorize, execute, track state, verify, recover

Blender
    -> production execution through a controlled adapter

Independent verification
    -> establish authoritative resulting state

Qwen must never receive direct execution authority.

============================================================
