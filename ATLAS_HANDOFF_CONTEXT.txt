============================================================
1. PROJECT
============================================================

Atlas is a local Blender environment-acquisition agent.

Core architecture:

User task
    ↓
Python orchestrator
    ↓
Local Qwen/Ollama model
    ↓
Reasoning and evidence selection
    ↓
Blender tools
    ↓
Evidence ledger
    ↓
Python controller when an authorized action is required
    ↓
Independent verification
    ↓
Final-answer validation or deterministic finalization

Core principle:

Qwen handles reasoning and interpretation.
Python handles execution, state, mandatory actions, verification,
and completion control.

The complete conditional control loop is now proven:

Qwen proposal
    ↓
Python validation
    ↓
Read-only evidence
    ↓
Target-state decision
    ├── already correct → NO-OP → independent verification
    └── incorrect → authorization → writes → independent verification

This is a major milestone because Qwen proposes, but Python decides whether
a write is necessary, controls authorization, controls execution, and verifies
the result.

============================================================
6. GENERAL ACTION PLANNING V1
============================================================

A generic module exists:

action_plan.py

It defines ActionSpec and ActionPlan for ordered authorized actions.

The plan exposes the current action, records successful results, advances only
after success, blocks after required failure, reports completion, and produces
a serializable snapshot.

This remains intentionally separate from the goalpost controller.

============================================================
7. GENERAL EVIDENCE PLANNER V1
============================================================

A generic module exists:

evidence_plan.py

It tracks ordered evidence requests, completion, reuse, and blocking failures.

============================================================
8. PLANNING ORCHESTRATOR V1
============================================================

planning_orchestrator.py connects evidence and action plans.

It blocks action execution until required evidence is complete and exposes
the next authorized action without requiring another model reasoning cycle.
