============================================================
1. PROJECT
============================================================

Atlas is a local Blender environment-acquisition agent.

Core architecture:

User task
    ↓
Python orchestrator
    ↓
Local Qwen/Ollama model
    ↓
Reasoning and evidence selection
    ↓
Blender tools
    ↓
Evidence ledger
    ↓
Controller when an authorized action is required
    ↓
Independent verification
    ↓
Final-answer validation or deterministic controller finalization

Core principle:

Qwen handles reasoning and interpretation.
Python handles execution, state, mandatory actions, verification,
and completion control.

9. LIVE FAILURE FOUND
============================================================

The Blender modification did not fail.

The controller did not fail.

The independent verification did not fail.

The first live run failed during final-answer generation.

Qwen produced incomplete final answers, the validator correctly rejected
them, and the reasoning loop eventually reached its step limit.

This showed that successful controller work should not depend on Qwen
being able to formulate the final report after the state is already proven.

10. FINALIZATION RECOVERY
============================================================

Added:

controller_finalization.py

When the controller has:

- BEFORE relationship evidence
- successful required writes
- FINAL relationship evidence
- the required final state

The report separates:

INITIAL MEASURED STATE
CALCULATED TARGET STATE
FINAL VERIFIED STATE

This is a recovery path for controller-owned tasks.

Normal non-controller tasks still use the normal Qwen final-answer path.
